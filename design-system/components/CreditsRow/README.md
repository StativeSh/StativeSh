# CreditsRow
A film-credits style row of facts about a project: a small label above a large value, in `tan` Anton.

**Use** directly under a project's `MegaTitle`, with three or four items: what it is built with, its format, what it covers, its status. Match the row's colour to the project title (`tan`, `pink`).

**The consumer provides** the items as `<span><small>Label</small>Value</span>`. On phones the row becomes an even two-column grid.

Keep values to a few words; this is not a feature list.

# TapedNote
A black card taped onto ruled paper at a slight angle, for personal notes away from the main work.

**Use** in a ruled band, three in a row (`.si-notes`), each with a different tape colour: default `tan`, `.si-note--lavender`, `.si-note--pink`.

**The consumer provides** a red display label (`.si-k`), a title (`<h3>`) and one line, or a short table.

Notes rotate -1.2 / +0.8 degrees alternately. Don't use them on ink; the tape and shadow are made for bone.

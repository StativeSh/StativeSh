# HeroTitle
The page's opening headline: huge condensed uppercase lines in `bone` with a hard `deep` extrusion, the last phrase in `red`.

**Use** once per page, one phrase per `.si-line`, three or four lines. Put a `.si-hello` scrawl above it and a `.si-lede` under it.

**The consumer provides** the lines. Keep each short enough not to wrap (`white-space:nowrap`); at phone width the type scales down (`t-hero`, fluid 56 to 122px).

Don't use it for section titles; those are `MegaTitle`.
